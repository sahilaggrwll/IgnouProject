Defense-in-Depth Security Layers

3
Application Level

  • Bcrypt Hashing: Secure one-way encryption for all stored user passwords.

  • JWT Authentication: Stateless token-based access control for API endpoints.

  • Input Validation: Strict sanitization of Git URLs and project names.

2
Network Level

  • Pod Isolation: Network policies prevent containers from communicating with each other.

  • Internal Routing: Apps are only accessible via the Nginx reverse proxy, not directly exposed.

  • Firewall Rules: Strict GCP firewall configuration allowing only essential ports.

1
System Level

  • Namespace Isolation: Containers run in isolated Linux namespaces (PID, IPC, Mount).

  • Resource Limits: Kubernetes enforces CPU and RAM caps to prevent DoS.

  • Restricted FS: Containers have no access to the Ubuntu host filesystem.
