Roadmap

Future Scope & Enhancements

Targeting v2.0

Scalability & Automation

While the current iteration establishes the core PaaS foundation, the next phase focuses on seamless enterprise integration, full CI/CD automation, and advanced resource management.

True CI/CD Integration

Implement GitHub/GitLab webhook listeners to automatically trigger new build-and-deploy pipelines whenever code is pushed to the repository branch.

Auto-Provisioned Databases

Enable users to request dedicated database containers (PostgreSQL, MongoDB) attached to their application network with auto-injected environment variables.

Private Repo Authentication

Add OAuth 2.0 and SSH key management to allow cloning from private repositories and organizations, expanding support beyond public open-source projects.

Advanced Monitoring

Integrate Prometheus and Grafana for real-time visualization of container CPU usage, memory leaks, and request latency metrics directly in the user dashboard.
