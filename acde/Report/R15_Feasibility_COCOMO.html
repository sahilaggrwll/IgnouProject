2.3 Feasibility Study — Four Dimensions

Technical Feasibility

Technology Availability

All required tools — Node.js, Docker Engine, Kubernetes (minikube), MongoDB, and Nginx — are mature, open-source, and freely available on Ubuntu 20.04+. The developer has prior experience with all core technologies.

Feasible

Operational Feasibility

Workflow Integration

ACDE's single-API-call model dramatically reduces operational overhead. Developers need only a Git URL — the system handles all provisioning. The SSE-based log dashboard provides real-time visibility without training.

Feasible

Economic Feasibility

Cost & Resources

Zero-cost open-source software stack. Single developer on available hardware (16 GB RAM, 50 GB SSD). GCP production costs estimated ₹800–₹2,000/month for low traffic — well within feasibility range.

Feasible

Schedule Feasibility

Timeline Viability

COCOMO estimates 4.27 person-months of effort, completing in ~5 months — matching the planned 5-sprint Agile timeline. The 5-month window aligns with the IGNOU MCSP-232 submission window.

Feasible

Overall Verdict: Feasible. All four dimensions confirm ACDE is technically sound, operationally practical, economically viable, and schedulable within the given timeline.
