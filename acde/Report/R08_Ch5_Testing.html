5.1 Testing Strategy & Plan

ACDE employs a multi-level verification approach using the Mocha + Chai testing framework with a live MongoDB test database. Three tiers of coverage are applied:

Unit

Login handling, Git URL validation, request sanitisation

Integration

Clone → build → status update, MongoDB writes confirmed

System / Security

Live routing, failure logging, ownership enforcement

Pass Criteria

Expected status codes and DB records produced.

Fail Criteria

Errors logged; deployment status set to failed.

Exit Condition

All 5 sample cases pass before submission.

5.4 Debugging — Errors Encountered & Resolved

Error: Bind for 0.0.0.0:31000 failed — port already allocated

Cause: Port allocator only queried MongoDB; orphaned Docker container still held the port at OS level.
Fix: Added isPortFree(port) using net.createServer() to probe TCP bind before allocation (ports.js).

Error: MongoServerError — E11000 duplicate key (email)

Cause: Parallel test runs both tried to insert the same seed user email.
Fix: Added before() hook in test suite to drop the users collection; after() hook to clean up.

Error: SSE stream closed prematurely on long builds

Cause: Nginx default proxy_read_timeout of 60 s killed the streaming connection mid-build.
Fix: Added proxy_read_timeout 3600s; to the Nginx conf template for SSE endpoints.
