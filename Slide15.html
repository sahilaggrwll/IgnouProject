Risk Analysis

Identified Risks & Mitigations

Risk Level Impact Mitigation
Docker daemon unavailable High Entire deployment pipeline blocked; no image build possible. Dashboard health-check detects Docker status at startup and on each deploy attempt.
Port range exhaustion Medium New deployments fail to allocate host port; service unavailable. Allocator probes OS-level port availability; configurable range (default 31000–31999).
Git clone failure (private / invalid URL) Medium Deployment fails at first pipeline stage. URL validated before pipeline starts; error is logged and deployment marked failed gracefully.
MongoDB connection loss High API cannot read/write project or deployment state. Mongoose reconnects automatically; health endpoint exposes connection status.
Kubernetes apply failure Medium K8s deployment rejected; app not accessible via cluster. Orchestrator automatically falls back to plain Docker mode; error is logged.
Unauthorised project access Low Data leak between users if ownership not enforced. JWT middleware + ownership guard on every route; returns 403 on mismatch (TC-05).
Container resource abuse Low Single container starves host CPU/RAM. K8s resource limits: CPU 500m, Memory 512Mi per pod. Docker: no extra caps in v1.
